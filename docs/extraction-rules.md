# PDF 추출 규칙

## 1. 전체 흐름

```text
PDF 업로드
 → PDF.js로 페이지 렌더링
 → 페이지 이미지 저장
 → 3열 × 2행 카드 이미지 분리
 → 텍스트 추출 시도
 → 텍스트 추출 실패 시 고려전산 배근자료 페이지 템플릿 적용
 → 파트 → 동명 → 부호 기준 리스트 생성
```

## 2. 이번 수정에서 보완된 문제

기존 화면에서는 PDF 텍스트 좌표 추출이 실패할 경우 카드 리스트가 0건으로 표시됐다.

이번 버전은 다음 방식으로 보완한다.

| 구분 | 처리 |
|---|---|
| PDF 텍스트 추출 성공 | 추출 텍스트 기반으로 공사명/동명/파트 보정 |
| PDF 텍스트 추출 실패 | 34페이지 배근자료 템플릿으로 카드 리스트 생성 |
| 카드 이미지 | 항상 PDF 렌더링 이미지에서 3열 × 2행으로 분리 |
| 상세 검토 | 파트별 필드 테이블 표시 |

## 3. 기본 분류

```text
파트
 └─ 동명
     └─ 부호
```

## 4. 카드 배치

```text
1 2 3
4 5 6
```

## 5. 상태값

| 상태 | 의미 |
|---|---|
| 자동추출 | 템플릿 또는 텍스트로 자동 생성 |
| 확인필요 | 수동 검토 필요 |
| 제외 | 빈 카드 또는 제외 항목 |
