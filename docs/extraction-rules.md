# PDF 추출 규칙

## 전체 순서

```text
PDF 업로드
 → 브라우저에서 PDF.js로 PDF 읽기
 → 페이지 텍스트 추출
 → 페이지 이미지 렌더링
 → 공사명 / 동명 / 파트 / 페이지 번호 추출
 → 3열 × 2행 카드 영역 분리
 → 카드별 이미지 생성
 → 카드별 명칭 / 부호 추출
 → 파트별 분류
 → 리스트화
```

## 헤더 추출 예시

```text
[공사명] [현대엔지니어링]용인 TEL 반도체 제조장비 T [동명] FAB (동별범위) 기초 - 1 Page
```

## 추출값

| 항목 | 예시 |
|---|---|
| 공사명 | [현대엔지니어링]용인 TEL 반도체 제조장비 T |
| 동명 | FAB |
| 파트 | 기초 |
| 페이지 | 1 |

## 카드 분리

한 페이지를 기본적으로 3열 × 2행으로 나눈다.

```text
1 2 3
4 5 6
```

## 상태값

| 상태 | 의미 |
|---|---|
| 자동추출 | 명칭 또는 부호가 추출된 항목 |
| 확인필요 | 텍스트 추출값이 불완전한 항목 |
| 제외 | 빈 카드 또는 분석 제외 |
```
