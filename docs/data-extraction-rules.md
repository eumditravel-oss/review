# 데이터 추출 규칙

## 목적

이 버전은 원본 이미지를 잘라 보여주는 것이 아니라, 각 파트별 일람표에서 사이즈, 철근 규격, 개소, 간격을 추출하는 것을 목적으로 한다.

## 처리 방식

1. PDF 텍스트 레이어에서 1차 값 추출
2. 값이 비어 있으면 선택 카드 OCR 정밀분석
3. OCR 결과를 파트별 규칙으로 분류
4. 사용자가 표에서 직접 수정 가능
5. JSON/CSV 다운로드 시 수정값 포함

## 파트별 주요 필드

- 기초: 두께, 우마철근, 상부/하부 부근, 상부/하부 주근
- 기둥: 가로/세로, 주근, 보조주근, 대근 상중하, 보조대근
- 보: 내단부/중앙부/외단부별 상부근, 하부근, 늑근, 보조늑근, 보조근
- 슬라브: 두께, 상부 주·부근, 하부 주·부근
- 옹벽: 수직/수평 외부/내부, CUT근, 폭고정근
- 계단: 참부/계단부, 주근/부근, 보강근
