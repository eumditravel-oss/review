# GitHub Pages 배포 가이드

## 1. 업로드

압축을 해제한 뒤 아래 파일 전체를 GitHub Repository에 업로드한다.

```text
index.html
README.md
assets/
docs/
sample/
.gitignore
```

## 2. Pages 설정

```text
Settings → Pages
Source: Deploy from a branch
Branch: main
Folder: /root
```

## 3. 테스트

생성된 GitHub Pages 주소에 접속한 뒤 PDF를 업로드하고 `분석 실행`을 누른다.

## 4. 정상 결과

- 카드 수가 0건이 아니어야 한다.
- 좌측 파트별 구조에 기초, 기둥, 보, 슬라브, 옹벽, 계단이 표시되어야 한다.
- 동명 FAB, OFFICE, KINDERGARTEN, STORAGE, PARKING TOWER가 표시되어야 한다.
- 리스트에서 항목 선택 시 원본 페이지와 카드 이미지가 표시되어야 한다.
- 파트별 검토 필드가 표시되어야 한다.
