# PDF 배근자료 데이터 추출 시스템 - GitHub Pages 버전

이 버전은 단순히 카드 이미지를 잘라서 보여주는 화면이 아니라, 각 파트별로 필요한 **데이터 값**을 추출·검토할 수 있도록 수정한 버전입니다.

## 핵심 수정사항

- 기초, 기둥, 보, 슬라브, 옹벽, 계단별 데이터 필드 구성
- PDF 텍스트 레이어에서 카드별 텍스트 추출
- 선택한 카드에 대해 OCR 정밀분석 가능
- OCR 결과를 파트별 규칙으로 재분석
- 추출값을 표 형태로 표시
- JSON / CSV 다운로드 시 파트별 데이터 포함
- 원본 이미지는 보조 검토용으로만 사용

## GitHub Pages 배포

1. ZIP 압축 해제
2. 전체 파일을 GitHub Repository에 업로드
3. `Settings → Pages`
4. Source: `Deploy from a branch`
5. Branch: `main`
6. Folder: `/root`
7. 생성된 Pages 주소에서 테스트

## 주의사항

이 프로젝트는 GitHub Pages 정적 웹앱이므로 서버가 없습니다.  
PDF 내부 세부 철근값이 이미지로만 존재하는 경우에는 선택 카드의 **OCR 정밀분석** 버튼을 눌러야 값이 추출됩니다.

OCR은 브라우저에서 실행되므로 카드별로 3~10초 정도 걸릴 수 있습니다.
